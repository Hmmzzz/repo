# Hmmzzz Repo

Public iOS APT repository for rootless and RootHide packages.

Source: <https://hmmzzz.github.io/repo/>

## Packages

- **MarkFont** — system-wide font profiles for iOS 16 and later.
- **MarkTheme** — modular theme management for iOS 16 and later.

Each release is published separately for conventional rootless
(`iphoneos-arm64`) and RootHide (`iphoneos-arm64e`). GitHub Actions validates
every package, generates compressed APT indexes and deploys the repository to
GitHub Pages.
